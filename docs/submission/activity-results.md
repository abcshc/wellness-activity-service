# 건강활동 입력 검증 결과

이 문서는 비식별 검증 입력 네 건을 실제 MySQL과 HTTP API로 처리한 결과입니다. 원본 JSON과 `recordkey`는 포함하지 않습니다.

## 1차 검증 상태

| 항목 | 결과 |
| --- | --- |
| 검증 입력 | 4건 |
| 총 활동 이벤트 | 4,710건 |
| 최초 업로드 | 4,710건 생성, 항목 오류 0건 |
| 동일 입력 재전송 | 4,710건 생성 없이 무시 |
| 집계 정합성 | 원본의 KST 일별 기여값과 Daily·Monthly 결과 일치 |
| 검증 범위 | 원본 저장, 재전송 멱등성, 일별 집계 갱신, Daily·Monthly 조회 |

동시성·부하·성능 검증은 별도 단계에서 데이터 규모와 가상 사용자 수를 늘려 진행합니다. 현재 결과는 처리 정확성을 확인한 1차 검증 결과입니다.

## 검증 기준

- 활동 이벤트는 실제 `POST /api/v1/activities/steps` 경로로 최초 업로드한 뒤 같은 JSON을 한 번 더 전송했습니다.
- 최초 저장된 원본 이벤트만 KST 일별 집계에 반영되는지 확인했습니다. 재전송된 이벤트는 원본과 일별 집계 모두 바꾸지 않습니다.
- Daily는 2024-11-01부터 2024-12-31까지, Monthly는 2024-11부터 2024-12까지 조회했습니다.
- 일·월 경계는 `Asia/Seoul` 기준이며, 원본 이벤트 시각은 UTC로 정규화해 저장합니다.
- 수치는 API가 반환한 `BigDecimal` 값을 반올림·절삭하지 않고 표기합니다.
- 원천 `calories`가 0인 걸음 활동은 `steps × 0.04` fallback을 적용한 최종 `caloriesKcal`을 반환합니다.

## 원천값 없는 칼로리 처리

원천 `calories`가 0인 걸음 활동은 `steps × 0.04` fallback을 적용한 최종 `caloriesKcal`을 반환합니다. 원천값과 추정값의 구분, 적용 규칙 버전은 데이터베이스에 보관하며 API 응답에는 노출하지 않습니다. 최종 값은 개인별 정확한 에너지 소비량이 아닌 참고용 활동 지표입니다.

## Daily 조회 결과

날짜별 전체 결과는 [Daily 조회 결과](daily-results.md)에서 확인할 수 있습니다. 활동이 없는 날짜도 API 응답 그대로 `0`으로 포함했습니다.

## 결과 갱신

집계 로직 또는 검증 입력이 변경되면, 격리된 MySQL 환경에서 최초 업로드·재전송·일별 집계·Daily·Monthly 조회를 다시 실행해 이 문서와 Daily 결과 문서를 함께 갱신합니다. 원본 입력과 원본 사용자 구분 키는 공개 저장소에 추가하지 않습니다.
