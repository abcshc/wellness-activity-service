# 회원가입

> 상태: 구현 예정

## 목적

이름, 닉네임, 이메일, 비밀번호를 입력받아 회원을 생성합니다. 이후 인증과 건강활동 데이터의 소유자를 식별하는 기준을 제공합니다.

## 제공 기능

- 회원가입 요청 처리
- 이메일 형식 및 필수 입력값 검증
- 이메일 중복 가입 방지
- 비밀번호 단방향 해시 저장

## 데이터 항목

| 항목 | 설명 |
| --- | --- |
| 이름 | 회원의 이름 |
| 닉네임 | 서비스에서 사용할 닉네임 |
| 이메일 | 로그인 식별자 및 중복 가입 검증 기준 |
| 비밀번호 | 원문을 저장하지 않고 단방향 해시로 저장 |

## 설계 원칙

- 이메일은 정규화한 뒤 유니크 제약조건으로 중복을 방지합니다.
- 비밀번호 원문과 비밀번호 해시는 응답·로그에 포함하지 않습니다.
- 회원의 직접 식별 정보와 건강활동 데이터는 논리적으로 분리합니다.
- 서비스에서 이메일 중복을 먼저 확인하고, 동시에 발생한 요청으로 인한 중복 저장은 데이터베이스의 이메일 유니크 제약조건으로 차단합니다.

## 검증 기준

- 유효한 요청으로 회원가입할 수 있습니다.
- 필수 입력값이 없거나 이메일 형식이 올바르지 않으면 실패합니다.
- 이미 가입한 이메일로 다시 가입할 수 없습니다.
- 저장된 비밀번호 값은 원문과 다릅니다.
